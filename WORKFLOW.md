# Specification Workflow

```text
Human defines task
  -> check relevant sources and evidence
  -> Spec Authoring or Spec Review
  -> produce proposed edits or findings
  -> human resolves substantive decisions
  -> integrate the current-state document
```

## Stage principles

1. **Stage 2:** decide the architecture, procedures, and semantics first. Do not
   assume a design is correct merely because an existing Stage 3 candidate
   schema contains a corresponding field.
2. **Stage 3 review:** verify that each candidate protocol and schema construct
   conforms to the confirmed Stage 2 semantics and the authoritative 3GPP
   baseline.
